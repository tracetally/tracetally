Offline CLI

tracetally

Your LLM bill tells you the total. tracetally tells you why.

Point it at traces you already exported. JSONL, OTLP/JSON, Langfuse, and OpenAI usage CSV are enough. It prices the calls from a bundled table, ranks where the spend went, and writes a report on disk.

It is not a proxy, gateway, or SDK. It does not sit on the request path, hold provider API keys, send telemetry, or fetch prices. With no network, the audit still runs.

Install

pip install tracetally

Python 3.10 or newer. Apache-2.0.

Use

tracetally summary traces.jsonl
tracetally analyze traces.jsonl
tracetally report traces.jsonl --out ./audit
