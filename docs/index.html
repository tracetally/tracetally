Offline CLI

tracetally

Your LLM bill tells you the total. tracetally tells you why.

Point it at traces you already exported. JSONL, OpenTelemetry, Langfuse, and OpenAI usage CSV are enough. It prices those calls from a LiteLLM price-list download. --offline skips that download and uses the bundled snapshot. It ranks where the spend went and writes a report on disk.

Runs locally. Your data never leaves your machine. The only network request tracetally makes is a price-list download, which --offline turns off. No telemetry, no proxy, no LLM calls.

Install

pip install tracetally

Python 3.10 or newer. Apache-2.0.

Use

tracetally run
